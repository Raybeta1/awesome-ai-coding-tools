## Code Editors & IDEs

- [Cursor](https://cursor.sh/) - AI-first code editor built on VS Code. Multi-file edits, codebase awareness.
- [Zed](https://zed.dev/) - High-performance editor with built-in AI assistant. Fast, collaborative.
- [Windsurf](https://codeium.com/windsurf) - AI IDE by Codeium with deep context understanding.
- [Replit](https://replit.com/) - Browser-based IDE with AI assistant and instant deployments.
- [JetBrains AI](https://www.jetbrains.com/ai/) - AI assistant integrated into IntelliJ, PyCharm, and other JetBrains IDEs.

## Code Completion

- [GitHub Copilot](https://github.com/features/copilot) - AI pair programmer that suggests code in real-time.
- [Codeium](https://codeium.com/) - Free AI code completion for 70+ languages. Fast and accurate.
- [Tabnine](https://www.tabnine.com/) - AI assistant with privacy-focused, on-premise deployment options.
- [Supermaven](https://supermaven.com/) - Extremely fast completions with 1M+ token context window.
- [Amazon CodeWhisperer](https://aws.amazon.com/codewhisperer/) - Free AI code suggestions optimized for AWS services.

## Chat & Assistant Tools

- [Claude Code](https://claude.ai/code) - Terminal-based AI coding agent. Multi-file edits, runs commands, understands your codebase.
- [GitHub Copilot Chat](https://github.com/features/copilot) - Chat interface for code questions and explanations.
- [Aider](https://aider.chat/) - Terminal-based AI pair programmer. Works with any LLM.
- [Continue](https://continue.dev/) - Open-source autopilot for VS Code and JetBrains. Bring your own model.
- [Mentat](https://mentat.ai/) - AI coding assistant that edits multiple files and runs commands.
- [Orkas](https://orkas.ai/?source=gh_raybeta) - Local-first desktop workspace that coordinates specialist coding agents.
- [PearAI](https://trypear.ai/) - Open-source AI code editor with multiple model support.

## Code Review & QA

- [CodeRabbit](https://coderabbit.ai/) - AI-powered code review for pull requests. Detailed summaries and suggestions.
- [Greptile](https://greptile.com/) - AI code review and codebase search for teams.
- [CodeReview.ai](https://codereview.ai/) - Automated PR reviews with security and performance analysis.
- [What The Diff](https://whatthediff.ai/) - AI-powered code review assistant for automated PR descriptions.

## Testing & Debugging

- [Diffblue Cover](https://www.diffblue.com/) - AI that writes unit tests for Java code automatically.
- [CodiumAI](https://www.codium.ai/) - Generates meaningful tests for your code. Works with IDEs.
- [Kite](https://www.kite.com/) - AI-powered code completions and documentation lookup (archived, but influential).
- [Bugasura](https://bugasura.io/) - AI-powered bug tracking and triage.

## Documentation

- [Mintlify](https://mintlify.com/) - AI-powered documentation platform. Auto-generates docs from code.
- [Swimm](https://swimm.io/) - AI documentation that stays in sync with your code.
- [DocuWriter.ai](https://www.docuwriter.ai/) - Automatically generates documentation from your codebase.

## Command Line Tools

- [Claude Code CLI](https://docs.anthropic.com/en/docs/claude-code) - Terminal-based AI agent for coding tasks.
- [Open Interpreter](https://openinterpreter.com/) - Natural language interface for your computer in the terminal.
- [GPT-Pilot](https://github.com/Pythagora-io/gpt-pilot) - Build entire apps from scratch using AI.
- [Smol Developer](https://github.com/smol-ai/developer) - AI developer agent that builds entire projects.
- [Fabric](https://github.com/danielmiessler/fabric) - AI augmentation patterns for common tasks.

## APIs & SDKs

- [Anthropic API](https://docs.anthropic.com/) - Claude API for building AI-powered applications.
- [OpenAI API](https://platform.openai.com/) - GPT models for code generation and chat.
- [Groq](https://groq.com/) - Ultra-fast inference for open-source models like Llama.
- [Together AI](https://together.ai/) - Run open-source models with simple API.
- [Ollama](https://ollama.com/) - Run LLMs locally on your machine.
