# Contributing to Awesome AI Coding Tools

Thanks for your interest in contributing!

## How to Contribute

1. **Check for duplicates** — Search existing items before adding.
2. **Follow the format** — `- [Name](URL) - Short description.`
3. **Keep descriptions concise** — One sentence, max ~80 characters.
4. **Alphabetize** — Add items in alphabetical order within their section.
5. **Link to the main project site** — Not GitHub unless that's the primary page.

## Quality Standards

- Only add tools that are actively maintained or widely used.
- The tool must have a working website/repository.
- Avoid self-promotion of unfinished projects.

## Pull Request Process

1. Fork the repository.
2. Make your changes to `README.md`.
3. Open a PR with a clear description.

## Adding a New Category

If you're adding a new category:
1. Add it to the Contents list in alphabetical order.
2. Create the section heading with a descriptive name.
3. Follow the same list format.

---

Thank you for helping developers discover great AI coding tools!
